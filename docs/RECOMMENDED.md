# Recommended extensions

Veylora uses Open VSX. The following extensions are commonly useful and align with a privacy-first, modern workflow. They are **not** pre-installed; install them from Open VSX when you need them.

| Extension | Purpose | Notes |
| --- | --- | --- |
| Python (ms-python.python) | Python language support | Official Microsoft extension available on Open VSX |
| Pylance (ms-python.vscode-pylance) | Type checking / IntelliSense | |
| ESLint | JavaScript / TypeScript linting | |
| Prettier | Opinionated formatting | Works well with format-on-save |
| GitLens | Enhanced Git history | Optional; core Git is already present |
| Error Lens | Inline diagnostics | |
| vscode-icons or Material Icon Theme | File icons | |

## Notes

- Prefer Open VSX over the Microsoft Marketplace.
- AI-related extensions are optional. Veylora's own AI integration points remain off by default and provider-agnostic.
- For a new workspace, use **Veylora: Apply Modern Settings Profile** first; it sets telemetry off and several performance defaults.

See also the getting-started walkthrough inside the IDE.
