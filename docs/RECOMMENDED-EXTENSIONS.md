# Recommended extensions for Veylora

Veylora uses Open VSX (not the Microsoft Marketplace). These are privacy-friendly, commonly useful extensions that pair well with the product defaults. Install from the Extensions view after Open VSX is configured.

## Language & tooling

| Extension | Publisher | Why |
| --- | --- | --- |
| Python | Microsoft (or community ports) | Language support, when you want it. Prefer local analysis. |
| Pylance | Microsoft | Optional richer Python. Disable telemetry if available. |
| ESLint | Microsoft | Lint JS/TS without cloud. |
| Prettier | esbenp | Format on save (already encouraged by the modern profile). |
| GitLens | eamodio | Local Git history. Review telemetry settings. |

## Editor quality of life

- **Error Lens** — inline diagnostics.
- **Todo Tree** — local TODO scanning.
- **Better Comments** — pure UI.

## What we intentionally do not recommend by default

- Extensions that phone home for AI, telemetry, or analytics without an explicit opt-in.
- Anything that requires a Microsoft account or Marketplace-only features.

When you add an extension, check its settings for telemetry and set them to off if you want the same privacy posture as Veylora Core.

See also the getting-started walkthrough inside the IDE.
