# Recommended extensions for Veylora

Veylora stays privacy-first and does not force any third-party extension. The following are popular, well-maintained options that complement the product layer. Install only what you need from Open VSX.

## Language & framework

- **Python** (Microsoft) — or the Open VSX equivalent; pairs with the Python scaffold.
- **Pylance** / type checking if available.
- **ESLint** + **Prettier** for Node/web scaffolds.
- **GitLens** (optional) for richer git history.

## Productivity

- **Error Lens** — inline diagnostics.
- **Todo Tree** — track TODOs.
- **Project Manager** or multi-root helpers already in Veylora Core.

## Notes

- Prefer Open VSX gallery (configured in branding).
- Do not enable telemetry-heavy extensions by default.
- Contribution: open a PR against `docs/RECOMMENDED_EXTENSIONS.md` with rationale and Open VSX links.

See also `docs/AGENTS.md` for agent rules.
